# Run an analysis

**Where:** Analysis › Analyses

1. Click **+ New analysis**, name it and choose a typology. Its calibrated scenarios are listed.
2. Click **Run analysis**. The scenarios run in the background; enrichments read what they need on the way.
3. When the run ends, open its results. Each scenario shows how many units met each condition, step by step, and its
   findings.
4. Open a finding to see why: every condition, with the value that met it.
5. Click **Send to Alerts** to send the new findings. Findings already sent by an earlier run are not sent twice.

:::note What runs
Only calibrated scenarios run. A scenario without a calibration is listed but cannot run — see
[Calibrate a scenario](calibrate-a-scenario).
:::
